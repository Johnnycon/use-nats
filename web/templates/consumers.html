Demo 6 showed how JetStream streams store messages. This demo shows how consumers track where each service left off reading. A durable consumer remembers its position — if it crashes at order #5, it restarts at #6, not #1. An ephemeral consumer has no memory and starts fresh every time.

Try it: Run "Setup: Order Pipeline" to create the stream, a durable PaymentProcessor consumer, and 5 order events. Then pull messages and use Ack/Nak to control processing. Nak a message to see it get redelivered on the next pull.
