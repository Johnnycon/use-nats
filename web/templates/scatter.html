A price comparison engine needs to query multiple providers simultaneously and return all results. Unlike Request/Reply (Demo 2) which waits for the first response, scatter-gather broadcasts the request and collects all replies within a deadline. Fast providers appear instantly; slow ones arrive later -- but nothing blocks.

Try it: Click "Setup: Price Search" to create 4 providers with different response times. Then hit "Scatter: Search All" and watch replies stream in one by one. Try removing a slow provider or adding a new one to see how the results change.
